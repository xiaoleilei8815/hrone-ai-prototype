## 先说清楚：本地版和妙搭版是什么关系

这不是两套独立开发的工具，而是同一套纯静态网页的两种交付形态：

- `留存率统计/留存率看板工具/` 是唯一生产源码，也是可直接打开使用的本地版。
- `留存率统计/留存率看板工具/dist-miaoda/` 是从生产源码同步出来、用于飞书妙搭发布的副本。
- 两者共用相同的页面、统计引擎和Excel报表导出器，没有后端数据库。
- 以后只修改根目录生产源码。验证通过后再同步到 `dist-miaoda/`，不得分别修改、分别演进。

## 业务口径摘要

工具先筛选目标期间内首次派遣的唯一工号，再为每个人计算自己的观察期截止日：

```text
观察期截止日 = 首次派遣日期 + 留存观察天数N
考勤校验期 = 截止日-(M-1) 至截止日，首尾均包含
```

只有经过完整观察期的人才进入计分分母。工具综合最晚派遣日期、最近一次派遣结束日期和考勤校验期内的有效出勤，逐人判为留存、未留存、未成熟或待核验。有效出勤要求时长总计大于0，且确认状态为“已确认”或“已复核”。

观察天数可选7、14、30、60、90、180、365天或自定义；考勤校验期可选仅截止日、近7日、近14日、近30日或自定义。报表按成熟人员计算：

```text
留存率 = 留存人数 / 计分分母
计分分母 = 留存人数 + 未留存人数
```

`1-6月最晚派遣` 文件只用于交叉校验字段冲突和发现“整表剔除”的误伤风险，不得把出现在该表中的人员直接全部剔除。

## 怎样使用本地版

1. 用 Chrome、Edge 或其他现代浏览器打开 `留存率统计/留存率看板工具/index.html`。
2. 上传OTWS首次派遣队列文件；按需上传最晚派遣交叉表；上传覆盖所有个人考勤校验期的月度考勤文件。
3. 选择首次派遣队列日期、留存观察天数和考勤校验期。
4. 点击读取并校验数据，再应用口径并计算。
5. 先查看数据质量、未成熟和异常复核，再导出七张工作表的Excel报表。

所有上传文件只在当前浏览器内存中解析，不会由本工具上传到服务器。

## 怎样使用在线版

打开 [飞书妙搭公开版](https://ztn.feishuapp.com/app/app_17agg2v5asy/)，操作步骤与本地版一致。在线版同样在浏览器中解析文件并生成报表。发布新版本前，必须确认：

- 根目录和 `dist-miaoda/` 的待发布文件完全一致。
- 妙搭发布状态为 `finished`，且版本对应预期代码。
- 外部匿名用户能打开页面、上传数据、完成计算并下载报表。
- 下载报表的字段、工作表、公式、数字格式、动态区域和图表通过回归测试。

## 数据文件为什么不在交接包里

真实OTWS源文件和成品报表含姓名、工号、考勤及供应商信息，本交接包故意不附带这些个人数据。需要做真实数据回归时，请在受控环境把数据放到以下目录：

```text
留存率统计/欧洲/
留存率统计/美洲亚太/
```

文件名和字段合同详见《技术方案与交接手册》第5节。不得把真实员工数据、真实导出报表、登录凭证或飞书授权信息重新装入可外发版本。

## 变更红线

- 不得恢复 `(y-x)/z` 或“两天全场人数差”算法。
- 不得把出现于最晚派遣交叉表直接等同为未留存。
- 不得把未成熟、待核验人员塞进计分分母。
- 不得把人数列格式化成百分比，或把留存率列导出为普通小数。
- 不得只改 `dist-miaoda/`，也不得发布未同步的一部分文件。
- 不得在没有证据字段时自动豁免休假、减量、自然到期或雇主转换。
