OTWS｜劳务工管理系统

企业内部用户：组长、仓长、文员、HR、管理者、系统管理员

业务域末级菜单与功能
OTWS劳务工管理系统
内部协同主平台
工作台进入系统后的任务总览

工作台首页

查看待处理事项、关键指标、近期业务和快捷入口。

消息中心

统一查看待办／已办、通知／未读／已读；突出待办数量。

经营概览

查看用工规模、出勤、费用、供应商履约和异常概览。

供应商管理合作关系与商业资料

供应商名录

查询供应商、合作状态、服务区域、联系人和负责人。

准入与资质

提交、审核、补正和维护供应商资格及证照。

合同管理

维护合同、合作范围、期限、变更和续签记录。

报价管理

发起报价、比较方案、审批费率和设置生效版本。

协同账户

创建、停用供应商账户并分配合作范围与角色。

用工需求从需求提出到供应商响应

需求申请

组长提交岗位、人数、班次、地点、日期和用工要求。

需求审核

HR核对需求、退回补充或确认分发。

供应商分发

选择供应商、发送需求、跟踪接受、拒绝或部分响应。

缺口跟进

查看未满足人数、响应进度、补充安排和取消记录。

人员管理劳务工全生命周期

人员档案

查看身份、联系方式、供应商、岗位、资格和历史派遣。

入场与培训

办理入场、培训、试工、资格确认和在岗状态。

异动管理

处理调组、调仓、转供应商、离场和再次入场。

证件与资格

维护证件有效期、资格状态和到期提醒。

排班与调度确保人员按需求到岗

排班计划

按仓、岗位、班次和日期查看人员安排。

排班调整

调整班次、岗位、仓组和人员，提示冲突。

请假与替班

登记请假、安排替班并同步供应商。

加班管理

登记、核对和确认加班安排及依据。

考勤管理从打卡事实到确认工时

打卡权限

开通、暂停和恢复人员打卡权限，记录生效时间。

打卡记录

查询原始打卡、缺卡、重复卡和异常来源。

考勤计算

按地区、班次、休息、跨日和加班规则计算结果。

T+1考勤确认

组长／文员确认考勤，查看异常、修正并提交结果。

工时复核

查看供应商复核结果、争议证据和修正历史。

结算与报账从确认工时到付款进度

结算周期

按周、双周、月或自定义周期生成结算范围。

周期账单

汇总确认工时、费率、税费、币种和调整项。

HR账单确认

核对账单、预算和异常，确认或退回补正。

发票管理

核验供应商发票编号、币种、金额、附件和重复提交。

报账流程

自动发起内部报账，查看审批、打款和失败原因。

分析与系统设置支撑全球运营与治理

用工分析

分析人数、出勤、缺口、供应商质量和费用趋势。

组织与地区

维护企业、仓、组织、国家、地区、时区和语言。

周期与币种

配置周／双周／月等周期及 USD、GBP、EUR、CZK、PLN、JPY、KRW、CAD、AUD。

权限与审计

配置角色、数据范围、代理、操作记录和导出权限。

关键链路：需求申请 → HR分发 → 供应商排班 → 打卡与考勤计算 → 组长／文员T+1确认 → 供应商复核工时 → 周期账单 → HR确认 → 供应商复核并上传发票 → 自动报账 → 回传审批打款进度。

外部协同主平台
工作台供应商任务与进度总览

工作台首页

查看需求响应、排班、工时、账单、发票和收款进度。

消息中心

统一查看待办／已办和通知／未读／已读，按当前身份隔离状态。

收款概览

查看已报账、审批中、部分付款和已付款金额。

需求协同响应企业用工需求

待响应需求

查看HR发送的岗位、人数、班次、地点和日期要求。

需求响应

接受、拒绝或部分响应，并填写缺口和补充说明。

响应记录

查看历史响应、企业反馈、调整和取消记录。

人员管理维护供应商员工资料

员工档案

维护身份、联系方式、岗位、企业安排和派遣历史。

资格与证件

上传证件、培训证明、资格材料并关注有效期。

入场与离场

提交入场、离场、再次入场和异动信息。

排班调度把响应转成可执行安排

排班计划

按需求、仓、岗位、班次安排员工。

调班与替班

处理员工调班、请假、替班和临时补位。

冲突检查

提示同人重复排班、资格不符和班次冲突。

安排结果

将最终安排提交给企业并查看确认状态。

工时复核确认企业T+1考勤结果

待复核工时

查看组长／文员已确认的T+1考勤记录。

工时复核

逐条或批量确认工时，查看打卡、排班和异常证据。

争议与退回

提交异议、说明原因、上传证据并跟踪重核结果。

复核历史

查看处理人、时间、动作、结果和修正版本。

账单与发票完成账票确认

待复核账单

查看HR已确认的周期账单、工时、费率和调整项。

账单复核

确认账单或提出金额、人员、周期和费率异议。

发票上传

上传发票并校验编号、币种、金额、附件和重复性。

发票补正

处理退回原因，替换文件并重新提交。

报账与收款查看内部流程进度

报账记录

查看已提交账单的报账编号、状态和处理节点。

审批进度

查看内部审批、退回、补充资料和完成时间。

付款进度

查看部分付款、全额付款、失败和预计到账信息。

收款资料

维护收款账户、税务资料和可用币种信息。

成员与设置供应商内部治理

成员管理

邀请、停用供应商成员并分配对接人或管理者角色。

角色权限

限制成员可见企业、需求、员工、账单和收款数据。

企业合作资料

查看合作企业、服务范围、合同和报价确认信息。

操作记录

追踪成员、响应、复核、发票和资料变更历史。

关键链路：接收需求 → 响应需求 → 安排人员与排班 → 企业T+1确认考勤 → 供应商复核工时 → 企业HR确认账单 → 供应商复核账单 → 上传发票 → 查看报账审批 → 查看打款进度。
